
# Hand Gesture Classification

Brief description
- This repository contains experiments and visualizations for hand gesture classification across several datasets (ECEM, Selman, NinaPro, and custom data). It includes feature extraction, preprocessing, and classification using SVM, tree-based models (Random Forest, Extra Trees), and ensemble approaches (MEET).

Contents
- `custom_data/`: Experiments and preprocessing based on ECEM and Selman datasets (combined and custom datasets).
- `nina_pro/`: Experiments and scripts using the open-source NinaPro datasets.
- `outputs/`: Experiment outputs and visualizations (confusion matrices, plots, etc.).

Main topics
- Data preprocessing and windowing; feature extraction for hand gestures.
- Classification with SVM and tree-based models; per-class performance analysis.
- Ensemble strategies (MEET) and One-vs-One classification to improve results.

Notes
- Experiment results and confusion matrices are available in the `outputs/` folder.

## 🔗 References

- Dataset DB5: Upper limb kinematic and EMG signals
- NinaPro Protocol: Standard hand movement gestures
